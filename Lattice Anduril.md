#### [Lattice for Mission Autonomy](https://youtu.be/RpFFScTovII?si=H_mPz49H8JjVNEo6)
- software operating system
- allows for greater autonomy
	- you can have a smaller amount of people control a larger amount of systems
- combines a lot of different things...
	- sensor fusion
	- target identification and tracking
	- intelligent networking
	- CNC, command and control
**Mission Autonomy**
All of these things work together THROUGH lattice to automate some of the things that would take longer if humans did them, thus reducing the load on humans.

#### [Anduril's Lattice: A Trusted Dual Use Platform for Public Safety and Defense \| Anduril](https://www.anduril.com/news/anduril-s-lattice-a-trusted-dual-use-commercial-and-military-platform-for-public-safety-security)
- it is a super flexible system and is made to not be reliant on any particular sensor, network, or system
- all of this data is then filtered and process via AI, ML, etc. to retrieve the important information for users
- this immense flexibility allows for a highly adaptable platform that can be used in many different fields
**example**
[President Biden Demanded “High-Tech Capacity” for Border Security. Anduril’s Towers Are Delivering It. \| by Anduril Industries \| Anduril Blog](https://blog.anduril.com/president-biden-demanded-high-tech-capacity-for-border-security-805b7b5664b5)
- US Customs and Border Patrol doesn't have enough man power to properly survey the entirety of the US - Mexico border in some areas
- You can set up "sensor towers" that can take in a large amount of data, whether that's camera data or thermal imaging, or anything really
- the lattice system then bridges the gap, allowing for large scale data synthesis, and then reporting relevant / important information to USCBP, no longer a need for constantly manned cameras
	- this greatly reduces the load of having to manually survey the camera footage, as the lattice system monitors that large data input, and returns a much more manageable data output
**in short**
	1) literally any amount of type of sensors into the lattice system
	2) the lattice system will then process that data
	3) lattice outputs relevant and important data to users
