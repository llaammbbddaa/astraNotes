**this video describes ==version one== of yolo and is likely to not be up to date**
- object detection = localization (where an object is) + classification (what an object is)
- an improved rcnn
- looks at the entire image instead of just specified regions (like what rcnns do)
- relies on shapes instead of image texture
- yolo takes in a 448x448 sized image, if a larger image is provided, it will be converted to that size
- it also has 98 bounding boxes
- you input the image, and you get out a 7x7x30 tensor
	- the output grid is 7x7, which frames the image
	- the x30 represents the following:
		- 20 goes to twenty objects that the algorithm is trying to detect
		- 10 goes to each grid creating two bounding boxes, which each have the following
			- x coordinate, y coordinate, width, height, confidence of object being within the box generated by said coordinates (**five numbers**)
- the tensor is then run through an nms to remove duplicate boxes
**for ==newer== yolo models (yolo 26)**
- default input 640x640
	- if an input does not meet that threshold, it will instead be letterboxed
		this is instead of just squishing it down to that size, it will maintain the original aspect ratio and therefore, the precise shapes of the objects
		[17. Image Padding (Letterbox): YOLOv5 detect.py Series - YouTube](https://youtu.be/wHcLl5ZYZsE?si=BFYESP7uk6wjTn0x)
- instead of the 7x7x30, you have a 80x80, 40x40, and a 20x20
	for fine / small objects, medium objects, and coarse / large objects respectively
	this adds up to a total of 8400 possible locations instead of the original 98
- this then gets reduces to 300 via a confidence threshold, so no nms needed
	basically only the boxes with a confidence above a certain value are allowed to pass through
- the **working** (not in-training) model uses a "one-to-one" style selection method, which assists in not producing duplicates / overlapping boxes
	this is what allows for the confidence threshold to replace the nms, which speeds things up
**==additionally==, the newer models are better and faster**, duh.
